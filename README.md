# VELOCE

A cinematic luxury automotive website concept built as a single-page experience. VELOCE combines premium visuals, smooth motion, hover interactions, and scroll-triggered reveals to showcase hypercar-inspired branding in a polished dark interface [file:1].

## Overview

VELOCE is designed as a fictional high-end automotive atelier with sections for home, vehicle collection, model details, about, contact, and login access [file:1]. The interface emphasizes cinematic motion, glowing accents, and bold typography to create a premium showroom feel [file:1]. It is best suited as a portfolio concept, luxury brand mockup, or front-end design showcase [file:1].

## Features

- Full-screen hero section with parallax-style background motion and animated heading.
- Cursor trail effect inside the hero area for a high-end interactive feel.
- Featured vehicle cards with hover lift, glow borders, and zoom effects.
- Horizontal scrolling photo strip and cinematic image sections.
- Responsive model collection and detail layouts.
- About, contact, and login pages within the same single-page experience.
- Mobile slide-out navigation panel.
- Scroll-based reveal animations and image transitions.
- Premium dark theme with Tailwind CSS utilities and custom CSS effects [file:1].

## Getting Started

1. Clone the repository.
2. Open `veloce.html` in your browser.
3. No build tools or package installation are required.

### Local Preview

You can run it directly by opening the file:

```bash
open veloce.html
```

On Windows, double-click the file or open it with your browser.

## Customization

You can easily personalize the site by editing:
- brand text and model names,
- image URLs,
- pricing and performance stats,
- navigation labels,
- contact details,
- and animation intensity [file:1].

### Useful Style Variables

- `--accent-blue` controls the primary accent color.
- `--bg-deep` controls the main background color.
- `TRAILOPACITY`, `TRAILCOUNT`, and `TRAILDECAY` control the cursor trail behavior [file:1].
